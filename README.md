# llm-templates

This library is designed to provide configuration and instructions to any LLM that a company may use for generating text or code. It does this by providing templates component lintery and apps for an LLM to generate from, and generated a ModeFIle which the LLM can then use to generate text or code specific to the company.




## Warnings

### Dependencies are not being properly used in package.json
This is not a conventional multi module project. You will notice we dont share dependencies from the parent to the children. That is becasue we want the children to be generated by an LLM separatley. That code wont work if the parent has half the dependencies.
